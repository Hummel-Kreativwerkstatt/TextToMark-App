# TextToMark

**Ein Tool von Hummel Kreativwerkstatt**

Konvertiert PDFs, Word-, Excel- und weitere Dateien automatisch zu Markdown — spart dir spürbar Tokens und Kosten bei der Arbeit mit Claude, ChatGPT & Co.

---

## Was ist das?

Diese App konvertiert PDFs, Word-, Excel- und PowerPoint-Dateien sowie HTML und Text automatisch zu Markdown.

Der Vorteil: Wenn du diese Dateien danach bei Claude oder einer anderen KI hochlädst, verbrauchst du deutlich weniger Tokens (also weniger Kosten und schnellere Verarbeitung) — bei gleichem Inhalt.

## Installation

Keine Installation nötig. Einfach:

1. `TextToMark.exe` an einen beliebigen Ort speichern (z. B. Desktop)
2. Doppelklick zum Starten
3. Es öffnet sich automatisch ein Fenster + dein Browser mit der App

> **Hinweis:** Der erste Start kann ein paar Sekunden dauern.

## Bedienung

1. Dateien per Drag & Drop hochladen (oder anklicken)
2. Auf **"Konvertierung starten"** klicken
3. Markdown-Dateien einzeln oder als ZIP herunterladen
4. Diese Markdown-Dateien statt der Originale bei Claude hochladen

## Unterstützte Dateitypen

| Format | Endung |
|---|---|
| PDF | `.pdf` |
| Word | `.docx` |
| Excel | `.xlsx` |
| CSV | `.csv` |
| PowerPoint | `.pptx` |
| HTML | `.html` |
| Text | `.txt` |

> ⚠️ **Wichtige Einschränkung:** Reine Bilder/Screenshots (PNG, JPG) liefern aktuell **keinen** Text — die App liest bislang keine Texte aus Bildern heraus (keine Texterkennung/OCR). Für diese Dateitypen bringt die Konvertierung also keinen Nutzen.

## Beenden

Die App läuft über ein Konsolenfenster (schwarzes Fenster im Hintergrund) — das ist normal, kein Fehler. Zum Beenden einfach dieses Fenster schließen (X-Button oder `Strg+C`).

## Windows-Warnung beim ersten Start

Windows zeigt beim allerersten Start evtl. eine Meldung wie *"Windows hat den Start dieser App verhindert"* oder *"Unbekannter Herausgeber"*. Das ist normal bei kleinen Tools ohne teures Code-Signing-Zertifikat und kein Anzeichen für einen Virus.

Einfach auf **"Weitere Informationen"** → **"Trotzdem ausführen"** klicken.

## Häufige Fragen

**Kostet die App etwas?**
Nein, kostenlos.

**Brauche ich Internet?**
Für die Konvertierung selbst nein. Die Token-Zählung läuft komplett offline (Vokabeldateien sind bereits eingebaut).

**Geht Information beim Konvertieren verloren?**
Nein, Text, Struktur, Tabellen und Überschriften bleiben erhalten.

**Werden meine Dateien irgendwohin hochgeladen?**
Nein. Alles läuft ausschließlich lokal auf deinem PC.

**Die App zeigt seltsam übersetzte Wörter (z. B. "Steckdose" statt "PowerPoint")?**
Das ist die automatische Übersetzungsfunktion deines Browsers (Chrome/Edge), die die Seite fälschlich übersetzt. Einfach im Browser die automatische Übersetzung für diese Seite ausschalten.
